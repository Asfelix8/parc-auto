Sauvegarde et importation

Les données sont conservées dans Supabase. L'export JSON télécharge une copie des données actuellement accessibles à votre compte.

L'import ajoute les lignes après confirmation. Testez d'abord avec quelques données. Une connexion Internet est nécessaire.

La restauration JSON et l'effacement global ne sont pas activés dans cette version test, afin d'éviter une perte accidentelle de données.

Comptes utilisateurs

Administrateur : gestion des véhicules, documents et entretiens. Responsable du parc : ajout et modification. Consultation : lecture seule.

La création des comptes directement dans l'application nécessite une fonction serveur sécurisée ; elle n'est pas encore disponible dans cette version. Les comptes peuvent être créés dans Supabase Authentication par l'administrateur du projet.
