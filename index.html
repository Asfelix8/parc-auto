Sauvegarde et transfert

Les données de cette application sont stockées dans le navigateur de cet appareil. Exportez régulièrement une sauvegarde JSON et gardez-la dans un emplacement sûr.

L’importation Excel ajoute les véhicules, documents et interventions trouvés dans les feuilles « Vehicules », « Documents » et « Maintenance ». Faites d’abord une sauvegarde JSON. Vérifiez ensuite les données importées. Une connexion Internet est nécessaire au moment de lire le fichier Excel.

La restauration JSON remplace les données locales actuelles. Exportez d’abord vos données avant de restaurer une sauvegarde.

Installation sur Android

  1. Publier ces fichiers sur un hébergement HTTPS ou les ouvrir via un serveur web local adapté.
  2. Dans Chrome Android, ouvrir l’adresse, puis menu ⋮ → « Ajouter à l’écran d’accueil » ou « Installer l’application ».
  3. Autoriser les notifications si le navigateur le propose.

Ceci est un prototype web installable, pas un APK natif signé. Les notifications fiables lorsque l’application est fermée nécessitent une version native ou un service de notifications configuré.
